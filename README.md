# Pathfinding Visualizer

Print a text grid and show a shortest path from S to E using breadth-first search (BFS).

## Run

Open this folder in VS Code and run:

```bash
python main.py
```

No extra packages are required.

## Try it

Try map 1 for a route, then map 2 to see the no-route message.

## How it works

Movement is up, down, left, or right. Walls (#) cannot be crossed. Map 2 is deliberately blocked.
